# 점수와 집계 기준

표현 강도는 -2~+2입니다. 구절 우선 매칭과 부정·강조·완화 규칙을 적용하고, 겹치는 근거는 긴 구절 하나를 선택합니다. 근거 위치는 NFC 정규화와 공백 정리 후의 `normalized_text` 기준이며 원문 좌표가 아닙니다.

리뷰·카테고리 점수는 그 항목의 판정 가능한 근거 평균입니다. 기간 점수는 리뷰·카테고리 평균들의 동일 가중 평균이며 `50 + 25 × 평균 강도`로 표시합니다. 리뷰 길이·별점·좋아요 수로 가중하지 않습니다.

리뷰·카테고리 상태:

- positive: 긍정 근거가 있고 부정 근거가 없음.
- negative: 부정 근거가 있고 긍정 근거가 없음.
- neutral: 근거가 있으나 모두 0.
- mixed: 긍정·부정 근거가 모두 있음. 평균이 0이 아니어도 mixed.
- unscored: 판정 가능한 근거 없음. 점수는 null/CSV 빈칸.

`mention_rate = mentioned_reviews / total_reviews`이며 `scoring_rate = scored_reviews / mentioned_reviews`입니다. 긍정·부정·중립·혼합 비율은 모두 `scored_reviews`를 분모로 사용하며 서로 배타적입니다. 분모가 0이면 비율도 빈값입니다.

`unscored_mentions`는 카테고리를 언급했지만 근거를 얻지 못한 리뷰 수입니다. 인용·조건 규칙에 걸린 근거와 단순 특징 서술 등이 포함됩니다. `scoring_rate`는 사전의 판정 범위이며 정답률이 아닙니다.

기간은 작성일 기준입니다. 월·분기 집계에서 날짜 미상 리뷰는 제외됩니다. 필터가 없는 all 집계에서는 날짜 미상도 포함합니다. 날짜 필터가 있는 all 집계에는 날짜 미상이 포함되지 않습니다. 카페별 양 끝 관측 기간 사이의 빈 달도 출력합니다. 시작·종료일을 명시하면 그 범위의 빈 기간도 출력합니다.

`cafe_missing_date_reviews`는 카페별 날짜 미상 총수로, 각 기간 행에 반복 표시됩니다. 이 열을 월별로 더하면 중복이 됩니다. 비어 있는 기간은 전체 리뷰 수 0, 점수 없음으로 표시합니다.

10건 미만 ‘표본 부족’은 초기 운영 기준입니다. 10건 이상도 신뢰성이 보장되는 것은 아닙니다. 카페 점수 차이는 원문·출처·기간·언급 수를 함께 확인해야 합니다.

현재 규칙은 `안/못` 앞 부정(붙여 쓰기 포함), `지 않다/지 못하다` 뒤 부정, 부정 표현의 부정을 약한 긍정으로 처리합니다. 강조는 1.5배(±2 제한), 완화는 0.5배입니다. v0.2는 평가 어간 바로 뒤의 조건·희망·전언·불확실성·일부 긴 부정을 판정 제외합니다. ‘기대’가 있다는 이유만으로 절 전체를 제외하지 않습니다. 복잡한 어미·긴 인용·부정 뒤 전언은 여전히 오판할 수 있습니다.

단독 `주차:`처럼 항목 이름만 있는 줄은 바로 다음 절의 대상 연결에만 사용합니다. 그다음 절까지 이어지지 않습니다. 일부 명사형 연결(`주문하는데`, `음료 나오는데`)은 분리하지 않아 대기 불만을 보존합니다.
