# 카테고리 분류 기준

| 코드 | 분류 | 포함 | 경계 |
|---|---|---|---|
| menu | 메뉴·맛 | 커피·음료·디저트의 맛·온도·식감·종류 | 비싸다는 value, 품절은 operation |
| service | 친절·서비스 | 응대·설명·주문 오류·요청 대응 | 단순 대기시간은 operation |
| space | 공간·분위기 | 좌석·소음·인테리어·뷰·작업 환경 | 주차·출입 동선은 location |
| location | 입지·접근성 | 길 찾기·역 거리·주차·출입 | 시설 내부 편안함은 space |
| value | 가격·가성비 | 가격·양·가격 대비 만족 | 메뉴 특징만 서술하면 menu |
| hygiene | 청결 | 식기·테이블·화장실 위생 | ‘인테리어가 깔끔’은 space |
| operation | 이용·운영 | 대기·혼잡·영업시간·품절·예약 | 주문 실수는 service |
| overall | 전반 만족 | 재방문·특정 대상 없는 총평 | 대상이 확실하면 해당 항목 |

하나의 리뷰에 여러 카테고리가 있을 수 있습니다. 하나의 겹치는 감성 표현은 중복 집계하지 않습니다. 카테고리 언급은 평가와 별개로 기록합니다. “주차는 모르겠어요”는 입지 언급이지만 감성 점수는 없습니다.

사전의 `auto`는 출력 카테고리가 아니라 연결 지시입니다. “좋다”, “별로다” 등은 같은 절의 가장 가까운 대상 단서에 연결합니다. 거리 동률이면 확인 필요로 남깁니다. 대상 단서가 전혀 없는 독립 총평은 overall로 처리합니다. 이 규칙은 문법적 관계 분석을 대신하는 초기 근사입니다.

“조용하다”, “산미가 있다”, “달다”, “지하다” 자체의 평가 방향은 고정하지 않습니다. 문맥에 나타난 선호와 불편 표현을 확인합니다.
