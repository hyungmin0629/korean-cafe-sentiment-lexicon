# 원문 검토 화면 사용법

v0.4.0은 사전 예측을 숨긴 오프라인 정답 작성 화면을 제공합니다. 사람의 독립 검토를 준비하는 도구이며, 도구를 만들었다고 실제 리뷰 정확도가 검증된 것은 아닙니다. 화면 버전은 0.1.0입니다.

## 화면 만들기

저장소를 내려받은 폴더에서 실행합니다. 입력은 [정답 작성 기준](annotation_guide.md)의 빈 양식이며, 각 리뷰에 8개 카테고리가 있어야 합니다. 이미 라벨·근거·검토자·메모가 들어간 양식은 거부합니다. 예측 파일·사전·별점·Codex 잠정 라벨은 읽지 않습니다.

```powershell
python tools/build_annotation_ui.py --input examples/annotations.synthetic.blank.csv --output outputs_private/review_demo.html
```

만들어진 HTML을 브라우저에서 엽니다. 별도 서버나 외부 AI API가 필요하지 않습니다. [자체 작성 4리뷰 예제](../examples/annotation.synthetic.html)도 내려받아 바로 열 수 있습니다. 예제의 정답은 모두 비어 있습니다.

현재 작업의 실제 검토 대상은 모모스·앤트러사이트 각 30개, 합계 60개 리뷰·480개 항목입니다. 원문이 있는 양식과 생성 화면은 로컬 비공개 폴더에만 있습니다.

```powershell
python tools/build_annotation_ui.py --input data_private/annotations.v03.holdout.blank.csv --cafes configs/collection.holdout_v03.json --output outputs_private/review_workspace_new/review.html
```

기존 출력 파일은 덮어쓰지 않습니다. 새 출력 이름을 사용하세요.

## 정답 작성 순서

1. 검토자 이름 또는 별칭을 입력하고 **검토 시작 / 이어가기**를 누릅니다. 다른 검토자는 다른 이름을 사용해 독립적으로 작성합니다.
2. 원문을 읽고 메뉴·친절·공간·입지·가격·청결·운영·전반 만족을 판단합니다. 긍정·부정·명시적 중립·혼합은 원문의 근거 구절을 그대로 입력합니다. 원문을 선택한 뒤 항목의 **선택 구절 넣기**를 사용할 수도 있습니다. 여러 근거는 줄바꿈으로 나눕니다.
3. 해당 항목의 평가가 없으면 **평가 없음**을 선택합니다. 의미나 대상이 모호하면 **판단 보류**를 선택하고 이유를 적습니다. 선택하지 않은 항목은 미검토로 남습니다.
4. 카페·검토 상태 필터와 다음 미완료 리뷰 버튼으로 이동합니다. 근거 누락·원문과 다른 근거·보류 이유 누락은 수정이 필요하며 CSV 내보내기를 막습니다.
5. **진행 상황 JSON 저장**으로 백업하고, **정답 CSV 내보내기**로 평가용 파일을 저장합니다. 저장 창의 내용을 복사해 UTF-8 파일로 보관할 수도 있습니다.

확정 항목·판단 보류·미완료 항목을 별도로 표시합니다. ‘8항목 검토 완료 리뷰’에는 이유를 적은 보류 항목도 포함되므로 정답 확정 완료율과 구분해서 읽습니다. 중간 CSV도 출력할 수 있지만 빈 정답은 평가에서 제외됩니다.

## 저장과 복구

입력은 리뷰 세트와 검토자 이름별로 브라우저에 자동 저장됩니다. 이름 입력만 바꾸면 저장 대상은 바뀌지 않으며, 시작 버튼을 눌러야 검토자가 전환됩니다. 같은 이름을 사용하면 동일한 저장본을 이어서 엽니다.

브라우저·기기·HTML 경로·접속 주소가 바뀌거나 브라우저 저장 공간이 지워지면 자동 저장본을 찾지 못할 수 있습니다. 장기간 보관·다른 기기 이동에는 JSON 파일을 사용하세요. JSON에는 리뷰 세트 해시가 있어 다른 입력 양식의 저장본을 거부합니다. **JSON 불러오기**는 해당 검토자의 입력을 저장본으로 바꾸며, **불러오기 전 입력 복구**로 이전 입력을 되돌릴 수 있습니다. 저장 공간 오류가 표시되면 자동 저장 완료로 간주하지 말고 파일 백업을 사용합니다.

실제 리뷰의 화면·근거·메모·백업·CSV는 비공개로 관리합니다. GitHub 예제에는 자체 작성 문장만 들어갑니다.

## CSV와 정확도 평가

CSV는 입력 양식의 모든 행을 유지합니다. 보류·미검토의 `gold_label`은 빈칸이며, 보류 이유는 `notes`에 남깁니다. `unscored`는 ‘평가 없음’이라는 확정 라벨입니다.

원문을 CSV에 다시 복제하지 않아 `text`는 빈칸이고, `input_text_sha256`에 원문 UTF-8 SHA-256을 넣습니다. 평가 도구는 출처·카페·리뷰 ID·카테고리를 연결하고 원문 해시가 예측 입력과 같은지 확인합니다. 이전 원문 포함 CSV도 계속 지원합니다. 검토자·메모·근거가 스프레드시트 수식으로 해석될 수 있는 문자로 시작하면 출력 앞에 작은따옴표를 붙입니다.

사람이 실제로 검토한 뒤 저장한 파일만 `--kind human`으로 평가합니다. 화면은 검토자 신원을 인증하지 않습니다. 기능 검증용 예제는 `synthetic`, Codex 잠정 판정은 `codex_provisional`로 구분합니다.

```powershell
python tools/evaluate.py --predictions outputs_private/actual_all_v031/reviews.jsonl --annotations data_private/annotations.v03.human.csv --kind human --split holdout --output outputs_private/evaluation.human.json
```

현재 실제 480행은 모두 빈 정답 상태이며 사람 정확도는 미측정입니다. 검토 후에는 두 검토자의 차이를 비교하고 합의 파일을 별도로 저장한 다음 카테고리별 누락·오판을 점검합니다.
