# 검증 결과와 한계

기준일 2026-10-12. 코드·사전·규칙 0.2.0. **사람 정답 기반 실제 리뷰 정확도는 미측정**이다.

## 기능 확인

`python -m unittest discover -s tests -v` 24개가 통과했다. 대상 연결, 부정·이중 부정, 중립·혼합·평가 없음, 띄어쓰기 생략, 인용·희망·불확실성 범위, 긴 구절 우선, 항목 제목, 대상 조건, 근거 좌표, 별칭, 날짜·기간·동일 가중 집계·중복·덮어쓰기 방지, 패키지 자원 일치, 평가 계산을 확인한다.

이 결과는 정한 기능 사례가 통과했다는 뜻이다. 실제 리뷰 정답률 100%를 뜻하지 않는다.

## 실제 입력과 후보 출현

| 입력 | 본문 | 감성 근거가 하나 이상 있는 리뷰 |
|---|---:|---:|
| 기존 3개 카페, v0.1 | 333 | 299 (89.8%) |
| 같은 333건, v0.2 | 333 | 311 (93.4%) |
| 확장 6개 카페, v0.2 | 501 | 463 (92.4%) |

전체 523레코드 중 빈 본문 22건을 제외했다. 분석 본문 중 작성 연도 미상 48건은 월별 집계에서 제외한다. 근거가 일부 확인 필요인 리뷰도 다른 근거가 판정 가능하면 위 수에 포함한다. 이 비율은 **판정 범위**이며 정확도·재현율이 아니다. 전체 기간과 월별 CSV, 상세 근거를 로컬 비공개 폴더에 저장했다.

후보 415개 중 개발 본문 221건(테라로사·프릳츠)에서 선택된 근거로 관찰된 것은 94개다. 나머지 321개는 표본에서 미관찰인 도메인 보완 가설이다. 겹친 구절에서 선택되지 않은 표현은 이 출현 집계에 포함되지 않는다. 모두 `candidate`이며 미관찰 여부와 검토 여부는 별개다. 항목별 건수는 `../lexicon/development_coverage.csv`에 있다.

레이어드·대림창고 본문 171건은 후보 추가를 위해 읽지 않은 보류 자료다. 실행 통계만 확인했다. 사람 정답 양식은 카페당 최대 30건을 ID 해시 순으로 고른 1,216개 항목 행이다. 추천순 수집 표본 안에서의 선택이며 전체 고객의 무작위 표본이 아니다. 실제 라벨은 모두 비어 있다. 사람 정답 없이 F1·정밀도·재현율·정답률을 계산하지 않았다.

나리나무 본문 2건도 같은 사전으로 실행했다. 메뉴 감성 근거는 1건, 다른 항목은 근거 없음이다. 1건은 작성 연도 미상이다. 카테고리별 운영 판단을 내릴 만큼 자료가 확보된 상태는 아니다.

사전 고정 후 보류 카페 12본문을 Codex가 직접 읽어 잠정 점검했다. 잠정 감성 평가 28행 중 9행을 놓치는 등 후보 확대 후에도 오류가 남는다. 사람이 작성한 정답과 분리해 보관하며 실제 정확도로 보고하지 않는다. `provisional_review.md`에 표본 구성·오류 유형을 기록했다.

## 처리 성능

Windows 11, Python 3.12.7. 짧은 자체 작성 문장을 반복한 생성 입력이며 실제 고객 리뷰 성능 표본은 아니다.

| 처리 범위 | 리뷰 | 시간 | 초당 리뷰 | 최고 메모리 |
|---|---:|---:|---:|---:|
| 분석·집계 | 10,000 | 2.836초 | 3,526.1 | 24.46 MiB |
| 분석·집계 | 100,000 | 27.839초 | 3,592.1 | 24.86 MiB |
| 전체 CLI 입출력 | 10,000 | 8.468초 | 1,180.9 | 미측정 |

분석·집계는 CSV 읽기·중복 ID 집합·JSONL 쓰기를 제외한다. 전체 CLI는 프로세스 시작, 입력 읽기, 중복 처리, 분석·집계, 상세 결과 약 30 MB 쓰기를 포함한다. 두 측정의 입력 문장은 서로 다르며 속도를 직접 비교하지 않는다. 최고 메모리는 같은 프로세스에서 두 분석·집계 규모를 순서대로 처리한 Windows 최고 작업 집합이다. 입력 생성 시간은 제외했다. `benchmark.json`, `benchmark_cli.json`에 측정 원본과 범위가 있다.

## 남은 품질 검증

1. 사람 두 명의 독립 라벨·의견 차이 합의와 카테고리별 품질 평가가 필요하다. `annotation_guide.md`와 `tools/evaluate.py`를 사용한다.
2. 큰 사전이라고 정확도가 보장되지 않는다. 미관찰 후보는 실제 사용 예·오탐을 검토해야 한다.
3. 단순 형태 규칙은 반어, 긴 부정, 복합 인용, 비교 대상, 대명사, 과거와 현재 평가를 충분히 해결하지 못한다.
4. 가까운 단서로 평가 대상을 연결하므로 실제 수식 관계와 다를 수 있다. 붙여 쓴 긴 문장과 임의 메뉴명은 누락될 수 있다.
5. 촉촉함·바삭함·진한 맛 등 후보의 기본 긍정은 취향에 따라 달라질 수 있다. 단순 산미·단맛 서술은 감성으로 확정하지 않는다.
6. 친절·입지·청결·운영은 실제 언급도 적다. 미판정 문장을 중립으로 채워 판정률을 높이지 않는다.
