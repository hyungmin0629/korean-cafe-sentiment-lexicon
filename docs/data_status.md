빈 본문 27건 제외. 월별로 사용할 수 있는 본문은 549건입니다. 추천순 공개 목록의 표본으로 완전 수집이나 전체 고객 대표성을 주장하지 않습니다. 네이버 429 응답 후 다이닝코드로 전환했으며 기존 매출·원가 자료는 사용하지 않았습니다.

입력은 `data_private/reviews.v03.csv`, 결과는 `outputs_private/actual_all_v03_final`와 `outputs_private/actual_month_v03_final`에 있습니다. 실제 HTML 보고서·원문·발췌·카페 감성 점수는 공개 묶음에서 제외합니다. 공개 데이터 역할·해시는 `dataset.v03.json`, 판정 범위는 `coverage.v03.json`입니다.

후보 420개 중 고정 개발 본문 221건에서 선택 근거로 관찰된 것은 95개입니다. 미관찰 325개도 모두 사람 검증 전입니다. 본문 624건 중 감성 근거가 하나 이상 있는 리뷰는 573건이며 이 건수는 정확도가 아닙니다.

나리나무는 본문 2건, 날짜 미상 1건, 메뉴 판정 1건입니다. 다른 항목은 평가 근거 없음을 표시하며 개선 우선순위·월별 추세를 보류합니다.

HTML 보고서와 기능 검사 35개, 생성 입력 10만 건 분석·집계와 1만 건 HTML 포함 CLI 실행을 완료했습니다. 생성 예제 보고서 250건은 실제 자료에 합치지 않았습니다.

새 보류 카페의 사람 라벨 양식 480행은 비어 있습니다. Codex가 별도로 작성한 잠정 라벨은 독립 사람 정답으로 취급하지 않습니다. 다음 핵심 과제는 사람의 분류 기준 합의, 독립 라벨 작성과 범주별 누락·오판 개선입니다.

v0.3.1에서 상단 시계열·전월 대비·월별 건수·월간 점수표를 추가했습니다. 현재 실제 보고서는 `outputs_private/actual_all_v031/report.html`입니다. 분류 동작과 위 실제 평가 통계는 v0.3.0과 동일합니다. 사전·규칙의 버전 정보만 갱신했으며 원래 v0.3 고정 자료의 해시는 `dataset.v03.json`에 보존했습니다.


v0.4.0에서 실제 60리뷰·480항목의 예측 비노출 검토 화면을 준비했습니다. 검토자별 자동 저장·JSON 백업/복구·정답 CSV 출력과 원문 해시 연결을 확인했습니다. Python 검사 40개와 JavaScript·브라우저 기능 검사를 통과했습니다. 실제 사람 정답은 여전히 0/480행이며, 다음 단계는 독립 검토·기준 합의입니다. 사전 후보·분류 동작은 v0.3.1과 동일합니다.
