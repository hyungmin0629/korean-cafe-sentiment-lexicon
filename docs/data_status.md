## 기존 자료 확인

상위 폴더의 파일 이름과 상권 전수조사 엑셀의 시트·열 이름을 확인했다. 상권 자료에는 리뷰 건수·별점·지도 링크가 있으나 리뷰 원문·작성일 전용 열은 확인되지 않았다. 점주 원가·매출 파일은 감성분석 입력으로 사용하지 않았다.

사용자가 실제 리뷰 크롤링과 ‘다른 카페로 먼저 개발하고 나리나무로 나중에 테스트’하는 순서를 지정했다. 네이버 직접 접속은 429 응답이었고, 읽을 수 있는 다이닝코드 공개 리뷰로 전환했다.

현재 사전으로 333건 중 하나 이상의 항목에 감성 근거를 얻은 리뷰는 299건이다. 이 비율은 판정 범위이며 정확도가 아니다. 날짜가 있는 리뷰 수와 감성을 판정한 리뷰 수가 우연히 같으므로 두 지표를 혼동하지 않는다.
