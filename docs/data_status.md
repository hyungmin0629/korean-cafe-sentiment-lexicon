# 데이터·작업 현황

기준일 2026-10-12, 버전 0.2.0.

상위 상권 자료에는 리뷰 건수·별점·지도 링크가 있으나 리뷰 원문·작성일 자료는 없었다. 사용자가 공개 리뷰 크롤링을 요청했다. 네이버 요청은 429 응답으로 중단하고 다이닝코드로 전환했다. 기존 매출·원가 자료는 분석 입력이나 공개에 사용하지 않았다.

추천순 공개 목록을 수집했다. 화면 표시 건수와 일부 수집 건수가 다르므로 완전 수집을 주장하지 않는다. 수집 기록과 캐시는 비공개다. 빈 본문 22건을 제외했고, 월별로 사용할 수 있는 본문은 453건이다.

합친 입력은 `data_private/reviews.v02.csv`, 전체 기간·월별 결과는 `outputs_private/actual_all_v02`, `outputs_private/actual_month_v02`에 있다. 카페별 감성 점수·원문·작성자 정보를 GitHub에 올리지 않는다. 공개 데이터 역할·해시는 `dataset.v02.json`, 판정 범위는 `coverage.v02.json`에 있다. 자체 작성 예제 18건은 실제 자료에 합치지 않았다.
