2026-10-13 후속 작업: 수동 리뷰 준비·변환 도구를 추가한 뒤, 사용자가 원하는 것은 각자 실행하는 네이버 플레이스 크롤러임을 확인했습니다. `tools/crawl_naver_place.py`, 별도 설치 목록, 선택자 설정과 실행 안내를 추가했습니다. 매장 URL에서 분석용 CSV를 만들고 선택하면 보고서를 생성합니다. 작성일·방문일은 구분하며 제한 응답에서 중단하고 확보한 행을 저장합니다.

Python 검사 56개가 통과했습니다. 자체 작성 5건 HTML, 모의 페이지 추가·중복·403/429 중단·CSV/보고서 연결을 확인했습니다. 사용자 링크의 ID `1649277590`은 URL 변환 시험에 반영했지만 개발 환경의 robots 요청이 429로 거절되어 이 지점의 실수집·실제 화면 선택자는 아직 확인하지 못했습니다. 실제 원문 624건·사전 후보 420개·사람 정답 미작성 상태는 그대로입니다. CSV 업로드 화면은 미구현이며 네이버 실수집 검증이 별도 남아 있습니다.

실제 Chrome를 사용한 로컬 샘플 시험에서도 외부 요청을 전부 차단/대체하고 더보기 2→5건, 403/429 중단을 확인했습니다. 기록은 비공개 `outputs_private/naver_browser_fixture_qa.json`에 있습니다. 실제 리뷰 수집 성공을 뜻하지 않습니다.
