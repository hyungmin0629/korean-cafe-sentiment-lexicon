# 검증 결과와 한계

2026-10-12, 코드·사전·규칙 v0.3.0. **사람 정답 기반 실제 리뷰 정확도 미측정.**

## 기능·보고서 확인

기능·평가 계산·보고서 검사 35개 통과. 부정·대상·혼합·인용·외부 평가·줄임말·나열, 날짜·빈 달·동일 가중 집계, 미판정 누락 계산, 제한된 발췌·테마별 중복 제외·주입 방지·이모지 강조 좌표를 확인했습니다. 기능 사례 통과가 실제 리뷰 정답률을 뜻하지 않습니다.

브라우저에서 카페·월 범위, 잘못된 범위 차단, 소량 표본, 전체·월별 CSV 값, 데스크톱과 모바일 표시를 확인했습니다. 내장 브라우저의 Blob 다운로드 완료와 PDF 저장 결과는 검증하지 못했습니다. CSV 복사 경로를 제공하며 자세한 범위는 `owner_report.md`에 기록했습니다.

## 실제 입력과 후보 출현

카페 8곳 본문 624건 중 감성 근거가 있는 리뷰 573건입니다. 작성 연도 미상 75건은 월별에서 제외합니다. 후보 420개 중 고정 개발 본문 221건에서 관찰 95개·미관찰 325개입니다. 모두 candidate입니다. 판정 범위와 후보 출현은 정확도·재현율이 아닙니다.

v0.2 오류 점검에서 읽은 레이어드·대림창고는 이번 개발 검토에 사용했으므로 최종 독립 평가 자료라고 부르지 않습니다. 모모스·앤트러사이트 123본문은 이번 분류기 수정에 사용하지 않았으며 고정 후 일부를 잠정 점검했습니다. 카페·역할·해시는 `dataset.v03.json`에 있습니다.

## 소량 잠정 점검

새 카페 10본문의 80항목 중 Codex 잠정 라벨 77개, 모호하여 보류한 빈 라벨 3개입니다. 평가 있음 25행 중 일치 11행, 누락 10행, 방향·혼합 차이 4행입니다. 평가 없음 52행은 모두 미판정입니다. 작성자가 개발자와 같은 Codex이고 표본도 작으므로 독립 사람 정확도로 보고하지 않습니다. `provisional_review.v03.md`를 참고하세요.

사람 라벨 480행은 모두 비어 있습니다. 정답이 없는 사람 평가는 도구가 계산하지 않습니다. 미판정 예측도 라벨이 있으면 누락으로 계산하고 neutral/mixed를 구별합니다.

## 처리 성능

짧은 자체 작성 문장을 반복한 생성 입력입니다. 실제 장문 리뷰의 성능 표본이 아닙니다.

| 처리 범위 | 리뷰 | 시간 | 초당 리뷰 | 최고 작업 집합 |
|---|---:|---:|---:|---:|
| 분석·집계 | 10,000 | 2.761초 | 3621.7 | 24.47 MiB |
| 분석·집계 | 100,000 | 27.607초 | 3622.2 | 24.55 MiB |
| HTML 포함 전체 CLI 입출력 | 10,000 | 8.969초 | 1114.9 | 미측정 |

분석·집계는 입력·중복 ID 집합·상세 결과·HTML 쓰기를 제외합니다. CLI는 프로세스 시작·CSV 입력·중복 처리·상세 결과·HTML 출력을 포함합니다. 두 측정은 입력 문장이 다르며 속도를 직접 비교하지 않습니다. 최고 작업 집합은 같은 프로세스에서 두 규모를 순차 실행한 값입니다. 측정 원본은 `benchmark.json`, `benchmark_cli.json`, 이전 기록은 `.v02.json` 파일입니다.

## 남은 검증

독립 사람 라벨·기준 합의, 간접 만족·재방문 이유, 공간 혼합 평가, 주문 불가·양 불만, 낯선 메뉴와 복합 대상 연결을 검토해야 합니다. 반어·대명사·과거와 현재·긴 부정·복합 인용도 한계가 있습니다. 검토 자료를 다음 사전 수정에 사용하면 새로운 최종 평가 표본이 필요합니다. 나리나무 2건으로 운영 판단이나 카페 순위를 확정할 수 없습니다.
