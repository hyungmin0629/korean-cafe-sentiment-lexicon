# 고정 사전의 소량 원문 점검

2026-10-12, 버전 0.2.0. 사전·규칙 고정 후 레이어드·대림창고 각 6본문을 Codex가 읽었다. 카페별 ID 해시 순서로 선택했고, 예측을 비교하기 전에 잠정 라벨을 작성했다. 사전을 만든 같은 Codex의 주관적 점검이며 독립 사람 평가가 아니다. 이 표본의 오류를 보고 v0.2 사전·규칙을 수정하지 않았다.

12본문 × 8항목 = 96행이다. Codex 잠정 라벨에서 감성 평가가 있다고 본 28행 중 예측 라벨이 일치한 것은 17행, 미판정으로 놓친 것은 9행, 방향·혼합 판정이 다른 것은 2행이었다. 평가가 없다고 본 68행 중 2행에는 감성 점수를 잘못 부여했다.

| 항목 | 잠정 라벨의 감성 평가 행 | 예측 라벨 일치 |
|---|---:|---:|
| 메뉴 | 10 | 9 |
| 친절 | 1 | 0 |
| 공간 | 5 | 3 |
| 입지 | 1 | 1 |
| 가격 | 6 | 3 |
| 청결 | 0 | 평가 사례 없음 |
| 운영 | 2 | 0 |
| 전반 | 3 | 1 |

평가 없음이 96행 중 68행이므로 전체 일치율만 보면 성능을 높게 착각할 수 있다. 표본이 작고 라벨도 잠정이므로 위 수를 실제 리뷰 정확도·카페별 검증 결과로 일반화하지 않는다. 사람 라벨 양식은 그대로 비워 두었다. 잠정 라벨·상세 오류·평가 도구 출력은 비공개 폴더에 별도 저장했다.

## 발견한 오류 유형

- 줄인 활용, 한글과 영문을 섞은 재방문 의사, 메뉴 외관의 귀여움 등은 아직 놓친다.
- 쉼표로 나열한 여러 항목에 하나의 부정 평가가 걸리면 뒤쪽 항목에만 연결할 수 있다.
- 다른 카페나 지역 물가의 평가는 현재 카페 감성으로 잘못 반영할 수 있다.
- 누군가의 추천과 실제 먹은 뒤의 직접 평가가 섞이면 대상·전언을 잘못 연결한다.
- 혼잡 불만·완곡한 가격 불만·공간 감탄처럼 직접적인 평가 단어가 적은 문장은 누락될 수 있다.
- 단순 규모·조용함 서술을 긍정으로 보는지, 좁은 간격 서술을 불만으로 보는지는 사람 간 기준 합의가 필요하다.

다음 수정에는 개발 자료에서 같은 유형의 별도 예문을 확보하고 새 평가 표본을 유지해야 한다. 후보 수 확대만으로 위 문제가 해결되지는 않는다.
