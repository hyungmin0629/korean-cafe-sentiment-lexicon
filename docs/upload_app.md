# CSV를 올려 카페 리뷰 보고서 만들기

네이버 크롤러나 이미 확보한 리뷰 CSV를 올리고, 입력 상태를 확인한 뒤 보고서를 생성하는 **로컬 분석 화면**입니다. 사람의 정답을 입력하는 `review.html`과는 별도입니다. 이 PC에서 Python 분석기를 실행하며 CSV를 외부 서비스에 보내지 않습니다. 네이버 자동 수집은 이 화면에 연결하지 않았고 [별도 크롤러](naver_crawling.md)를 사용합니다.

## 실행과 주소

Python 3.10 이상에서 저장소 폴더를 작업 위치로 사용합니다. 별도 라이브러리 설치는 필요 없습니다.

```powershell
python tools/serve_app.py
```

실행 창에 표시되는 [CSV 분석 화면](http://127.0.0.1:8766/)을 브라우저에서 엽니다. 서버가 실행 중인 이 PC에서만 열리는 주소입니다. 실행을 끝내면 새 접속과 새 분석은 멈춥니다. 이미 저장한 HTML 보고서는 서버 없이도 열 수 있습니다.

포트가 사용 중이면 이전 미리보기/분석 서버를 종료하거나 다른 포트를 지정합니다.

```powershell
python tools/serve_app.py --port 8767 --output outputs_private/web_runs
```

설치 패키지에서는 `python -m pip install .` 후 `cafe-review-app` 명령을 사용할 수도 있습니다. 저장소에서 실행하는 경우 기존 `/demo.html`·`/review.html`·`/report.final.html` 주소를 함께 제공합니다. 설치 패키지에 로컬 비공개 보고서·검토 자료를 포함하지는 않습니다.

## 화면에서 하는 일

1. CSV를 파일 선택 또는 끌어놓기로 올립니다. 파일이 없으면 **예제 CSV로 사용해 보기**를 누릅니다. 자체 작성 예제 250건, 2개 카페, 6개월 자료입니다.
2. **입력 확인하기**를 누릅니다. 전체 기록·사용 가능·작성일 확인·제외·작성일 미상·카페 수, 최초 5개 본문과 확인 내역을 봅니다. 이 단계에서는 아직 점수를 계산하지 않습니다.
3. 집계 단위와 선택적 시작일·종료일을 설정하고 **감성분석하고 보고서 만들기**를 누릅니다. 처리 중 상태를 표시하고 완료되면 **보고서 열기**와 다운로드 링크가 나옵니다.
4. 보고서에는 8개 항목·월별 변화·기간 합산·근거 표현을 표시합니다. 점수 CSV, 분석용 리뷰 CSV, 입력 확인 내역, 상세 JSONL과 실행 JSON을 저장할 수 있습니다.

분석 완료 후 기간을 바꾸면 이전 보고서 링크를 숨기고 입력 확인을 다시 안내합니다. 같은 파일을 다시 확인해 새 실행으로 보고서를 만들며, 이전 결과를 새 기간의 결과처럼 표시하지 않습니다.

두 열짜리 CSV는 카페 이름·지점과 출처를 한 번 입력합니다. 크롤러 CSV의 카페·출처·리뷰 ID는 유지합니다. 단일 카페 파일은 화면에서 표시명을 바꿀 수 있으며, 여러 카페 파일에서는 이름을 비워 기존 정보를 사용합니다.

기간을 비우면 보고서의 기간 합산에는 날짜 미상 리뷰도 포함합니다. 날짜를 지정하면 범위 밖·날짜 미상 리뷰는 집계에서 제외합니다. 상세 JSONL은 기존 분석기와 같이 전체 유효 입력의 결과를 저장합니다. 집계 단위는 점수 CSV에 적용되며 HTML 보고서는 월별 추세와 기간 합산을 함께 제공합니다.

## 받는 파일과 검사 기준

| 형식 | 필수 열 |
|---|---|
| 크롤러/분석용 CSV | `review_id,cafe_id,source,text` |
| 두 열짜리 CSV | `리뷰본문,리뷰작성일` 또는 `text,review_date` |

UTF-8/BOM CSV, 최대 10MB·20,000개 기록을 받습니다. Excel 파일은 CSV UTF-8로 저장합니다. 한 본문은 20,000자 이하입니다. 크기가 더 크면 카페나 수집 범위로 나누어 처리합니다. 20,000건의 전체 브라우저 처리 성능을 실측한 것은 아닙니다.

- 같은 출처·카페·리뷰 ID의 중복은 첫 기록을 사용합니다. 같은 문장이어도 ID가 다른 리뷰는 유지합니다. 두 열 입력에는 본문·원본 날짜·발생 순서로 ID를 생성합니다.
- 빈 본문·필수 정보 누락·빈 기록은 제외하고 확인 내역에 남깁니다. 중복 헤더·잘못된 열 수·깨진 CSV·사용 가능한 본문이 없는 파일은 분석을 시작하지 않습니다.
- 완전한 `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD`를 달력 검증 후 표준화합니다. 연도 없는 표시·잘못된 날짜는 원본 날짜 표시를 보존하고 작성일을 비웁니다. 방문일은 작성일로 변환하지 않습니다.
- 작성일 미상은 월별 집계에서 제외합니다. 기간 필터가 없으면 보고서의 기간 합산에는 포함할 수 있습니다. 방문일만 확인되는 기록도 화면에 별도로 안내합니다.
- 분석에 쓰지 않는 추가 열은 저장하지 않습니다. 리뷰 본문 내부의 쉼표·줄바꿈·이모지는 유지하고 HTML처럼 보이는 내용도 화면에 텍스트로 표시합니다.
- 선택한 날짜 범위에 집계할 리뷰가 없으면 보고서를 생성하지 않고 날짜를 다시 선택하도록 안내합니다.

## 산출물 저장

각 입력 확인 때 새 실행 폴더를 만들어 다른 결과를 덮어쓰지 않습니다.

```text
outputs_private/web_runs/<실행 ID>/
  input/reviews.csv             분석에 쓸 정규화 리뷰
  input/upload_issues.csv       업로드 입력 확인 내역
  job.json                     입력 요약과 실행 상태
  result/report.html           점주용 보고서
  result/summary.csv           카페·기간·항목별 점수
  result/reviews.jsonl          전체 입력의 리뷰별 상세 분석
  result/input_issues.csv       분석기 입력 검사
  result/run_metadata.json     사전·입력 해시와 집계 설정
```

올린 CSV의 원본 전체 파일은 따로 복제하지 않고 필요한 열로 정규화해 저장합니다. 실제 본문과 발췌가 있는 결과는 비공개로 관리합니다. 서버는 필요한 화면과 해당 실행의 결과 파일만 제공하며 폴더 목록을 공개하지 않습니다. 브라우저 새로고침/서버 재시작 후에는 입력을 다시 확인합니다. 완료한 파일은 로컬 실행 폴더에 남고 저장한 보고서는 독립적으로 열 수 있습니다.

## 확인한 동작과 남은 품질 과제

2026-10-13 기준 Python 검사 **67개** 통과. HTTP 업로드→검사→비동기 분석→HTML/CSV 출력, 날짜 필터와 빈 범위, 중복/필수 열, 추가 열 제외, 잘못된 출처/요청, 결과 경로 제한을 검사했습니다. 브라우저에서는 예제 250건, 실제 파일 선택의 크롤러 구조 CSV와 두 열 CSV, 오류 수정 후 재분석, 날짜 미상·방문일 안내, 보고서 8항목, 점수 CSV 다운로드, 모바일 너비의 한 열 배치·가로 넘침 없음을 확인했습니다. 모두 자체 작성 자료를 사용했습니다.

네이버 실수집은 robots 429로 0건에서 중단한 상태입니다. 새 분석 화면이 수집 문제를 해결한 것은 아닙니다. 사전 420개는 여전히 `candidate`이고 독립 사람 정답 기반 정확도도 아직 미측정입니다. 사용 흐름 검증과 분석 품질 검증을 구별합니다.
