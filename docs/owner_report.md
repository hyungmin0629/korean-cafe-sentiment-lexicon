# 소상공인용 리뷰 진단 보고서

v0.3.0부터 분석을 실행하면 결과 폴더에 `report.html`도 생성합니다. 파일을 브라우저에서 열면 인터넷 연결이나 서버 없이 사용할 수 있습니다. [생성 예제 보고서](../examples/report.synthetic.html)는 자체 작성 리뷰 74건으로 만들었으며 실제 매장 결과가 아닙니다. GitHub에서는 HTML 소스가 보이므로 파일을 내려받아 브라우저에서 여세요.

```powershell
python run.py --input examples/reviews.report.synthetic.csv --output outputs_private/report_demo --period month
```

## 읽고 활용하는 순서

1. 카페와 전체 기간 또는 월 범위를 선택합니다. 리뷰 수와 날짜 미상 건수를 먼저 확인합니다.
2. 메뉴·친절·공간·입지·가격·청결·운영·전반 만족의 점수와 판정 건수를 함께 봅니다. 평가 근거 없음은 점수 없이 표시합니다.
3. 항목 카드를 누르면 해당 항목의 월별 변화와 긍정·부정 근거가 선택됩니다.
4. 반복된 부정 표현을 원문과 매장 상황에서 확인합니다. 보고서는 원인이나 개선 효과를 추정하지 않습니다.
5. `현재 결과 CSV`에서 선택 범위의 8개 항목을 미리 보고 파일 저장 또는 복사합니다. `인쇄 / PDF`는 브라우저 인쇄 창을 엽니다.

월 범위 점수는 리뷰별 감성 합계와 판정 리뷰 수를 합쳐 계산합니다. 월 점수의 단순 평균은 아닙니다. 날짜 미상은 전체 기간에만 포함하며, 실행 시 `--start`·`--end`가 있으면 전체 기간에서도 제외합니다. 선택한 시작 월이 종료 월보다 늦으면 결과 표시와 내보내기를 보류합니다.

기본 판정 10건 미만은 ‘표본 부족’입니다. 추세 선은 연속된 월에 각각 10건 이상 판정된 구간만 연결합니다. 빈 달과 작은 표본은 연결하지 않습니다. 10건이라는 임시 기준을 넘었다고 정확도나 통계적 유의성이 보장되지는 않습니다.

‘먼저 확인할 점’은 항목 표본이 기준 이상이고 부정 또는 혼합 리뷰가 3건 이상인 항목을 반복 건수 순으로 최대 3개 제시합니다. 강점도 같은 방식으로 긍정 또는 혼합 리뷰를 집계합니다. 서로 다른 항목과 테마의 건수는 중복될 수 있습니다. 테마는 선택된 사전 근거를 묶은 것이며 모든 고객 의견을 추출한 결과가 아닙니다.

## 발췌와 공개

예시는 카페·기간·항목·감성 방향별로 기본 최대 3건을 보관합니다. 확인된 최신 작성일이 우선이며 전체 리뷰의 대표 표본은 아닙니다. 혼합 리뷰는 양쪽에 나올 수 있습니다. 본문 발췌의 강조 위치는 브라우저의 UTF-16 기준으로 변환하여 이모지가 앞에 있어도 근거를 맞춰 표시합니다.

실제 보고서는 리뷰 발췌를 포함하므로 비공개 결과 폴더에서 관리합니다. 공개 예제에는 자체 작성 문장만 넣었습니다. 발췌를 제외하거나 HTML 출력을 생략할 수 있습니다.

```powershell
python run.py --input data_private/reviews.csv --output outputs_private/no_excerpt --report-examples 0
python run.py --input data_private/reviews.csv --output outputs_private/csv_only --no-report
python tools/build_report.py --analysis outputs_private/csv_only --output outputs_private/csv_only/owner.html --examples 0
```

파일 하나에 스타일·스크립트·집계·제한된 발췌가 포함되며 외부 서버에 내용을 전송하지 않습니다. 실행 폴더의 원문 상세 파일은 별도로 비공개 관리해야 합니다. 큰 자료는 JSONL을 다시 순차 읽어 집계하고 발췌 수를 제한합니다. 카페·월 수가 늘면 보고서 크기도 늘며 무제한 규모나 브라우저 메모리를 보장하지 않습니다.

## 확인 범위

데스크톱과 390px 모바일 화면에서 필터, 날짜 누락, 작은 표본, 빈 점수, 그래프 보류, 근거 강조, CSV 미리보기를 확인했습니다. CSV의 전체 기간·월 범위 값은 집계 결과와 대조했습니다. Codex 내장 브라우저에서는 Blob 저장의 다운로드 완료 이벤트를 받지 못해 파일 저장 완료를 검증하지 못했습니다. 미리보기 복사를 대안으로 제공합니다. 인쇄/PDF 저장은 브라우저 대화상자에서 사용자가 수행하며 실제 PDF 페이지 출력까지 검증하지 않았습니다.

현재 점수는 검증 전 사전의 참고 감성지수입니다. 고객 만족 비율, 매장 품질 순위, 인과 분석과 구별하여 사용하세요.
